## 🎯 전체 흐름 (한눈에 보기)

```mermaid
graph LR
    Start([앱 시작]) --> Select[거래처 선택]
    Select --> Main[메인 화면]
    Main --> Work{무슨 일?}
    Work --> Order[발주]
    Work --> Sale[판매]
```

**간단 설명**:
1. 앱 시작 → 거래처 선택
2. 메인 화면 → 업무 선택
3. 발주/판매/견적/재고 등 작업

## 📱 시나리오 1: 병원에서 주문 받았을 때

### 상황
```
전화: "안녕하세요, A병원입니다.
       테이프 50개, 거즈 20개 주문합니다."
```

### 처리 과정

```mermaid
graph TD
    Start([전화로 주문 접수]) --> Open[앱 시작]
    Open --> SelComp{A병원<br/>선택됨?}

    SelComp -->|Yes| Main
    SelComp -->|No| ChangeComp[거래처 변경]
    ChangeComp --> SelA[A병원 선택]
    SelA --> Main[메인 화면]

    Main --> ClickSale[판매 탭 클릭]
    ClickSale --> Sale3Pane[판매 화면<br/>3분할 레이아웃]

    Sale3Pane --> Quick[우측: 자주 나가는 품목]
    Quick --> Input1[테이프: 50 입력]
    Input1 --> Check1{재고<br/>충분?}
    Check1 -->|500개 있음<br/>✅| Input2[거즈: 20 입력]
    Check1 -->|부족<br/>🔴| Warning[경고 표시]

    Input2 --> Check2{재고<br/>충분?}
    Check2 -->|200개 있음<br/>✅| Submit[판매 등록 클릭]

    Submit --> Auto1[자동: 재고 차감]
    Auto1 --> Auto2[자동: 채권 생성]
    Auto2 --> Done([완료!])

    style Start fill:#e1f5e1
    style Done fill:#e1f5e1
    style Warning fill:#ffebee
    style Auto1 fill:#f3e5f5
    style Auto2 fill:#f3e5f5
```

### 소요 시간
```
전화 받기      → 5초
거래처 확인    → 2초
판매 탭 열기   → 1초
수량 입력      → 10초 (테이프 + 거즈)
판매 등록      → 2초
───────────────────
합계: 20초
```

## 📦 시나리오 2: 도매에 발주할 때

### 상황
```
재고 확인 결과:
- 원재료A: 10kg 남음 (부족!)
- 부품B: 50개 남음 (부족!)
→ 추가 발주 필요
```

### 처리 과정

```mermaid
graph TD
    Start([재고 부족 확인]) --> Change[거래처 변경 클릭]
    Change --> Dialog{미저장<br/>데이터?}

    Dialog -->|있음| Confirm[확인 다이얼로그]
    Dialog -->|없음| Select

    Confirm --> Save[임시저장 후 전환]
    Confirm --> Discard[저장 안 함]
    Confirm --> Cancel[취소]

    Save --> Select[거래처 선택]
    Discard --> Select
    Cancel --> Stay[현재 화면 유지]

    Select --> SelB[B도매 선택]
    SelB --> Main[메인 화면<br/>B도매로 고정]

    Main --> ClickOrder[발주 탭 클릭]
    ClickOrder --> Order3Pane[발주 화면]

    Order3Pane --> Recent[우측: 최근 거래 품목]
    Recent --> Input1[원재료A: 100kg]
    Input1 --> Input2[부품B: 200개]

    Input2 --> Submit[발주서 보내기]

    Submit --> Auto1[자동: 구매 생성]
    Auto1 --> Auto2[자동: 입고예정 반영]
    Auto2 --> Done([완료!])

    style Start fill:#e1f5e1
    style Done fill:#e1f5e1
    style Auto1 fill:#f3e5f5
    style Auto2 fill:#f3e5f5
    style Stay fill:#fff3e0
```

### 소요 시간
```
거래처 변경    → 3초
발주 탭 열기   → 1초
품목 수량 입력 → 15초
발주 확정      → 2초
───────────────────
합계: 21초
```

## 💡 시나리오 3: 견적서 작성

### 상황
```
신규 거래처 "C병원"에서
견적 요청 전화가 왔습니다.
```

### 처리 과정

```mermaid
graph TD
    Start([견적 요청 전화]) --> Main[메인 화면]
    Main --> Change{C병원<br/>등록됨?}

    Change -->|No| AddComp[거래처 먼저 등록]
    Change -->|Yes| SelC[C병원 선택]

    AddComp --> SelC
    SelC --> ClickQuote[견적 탭 클릭]

    ClickQuote --> Form[견적서 작성 폼]
    Form --> AddProd1[품목 추가: 테이프]
    AddProd1 --> Modal1[품목 선택 팝업]
    Modal1 --> Close1[수량 입력 → 추가]

    Close1 --> AddProd2[품목 추가: 거즈]
    AddProd2 --> Modal2[품목 선택 팝업]
    Modal2 --> Close2[수량 입력 → 추가]

    Close2 --> Period[유효기간 설정]
    Period --> Send[발송 클릭]

    Send --> Wait{상대방<br/>응답}

    Wait -->|확정| Confirm[견적 확정]
    Wait -->|수정요청| Revision[새 버전 작성]
    Wait -->|거절| Reject[견적 거절]

    Confirm --> Auto1[자동: 단가 정책 반영]
    Auto1 --> Auto2[자동: 품목 리스트 등록]
    Auto2 --> Done([완료!])

    Revision --> Form

    style Start fill:#e1f5e1
    style Done fill:#e1f5e1
    style Auto1 fill:#f3e5f5
    style Auto2 fill:#f3e5f5
    style Reject fill:#ffebee
```

### 견적 확정 시 자동 처리
```
1. 단가 정책 반영
   → 이 거래처에 대한 품목 단가 저장
   → 다음부터 자동 적용

2. 품목 리스트 등록
   → "자주 거래하는 품목"으로 등록
   → 다음 견적/판매 시 우측에 표시
```

## 🔄 시나리오 4: 임시저장 활용

### 상황
```
발주서 작성 중 급한 전화가 와서
작업을 중단해야 함
```

### 처리 과정

```mermaid
graph TD
    Start([발주 작업 중]) --> Phone[급한 전화]
    Phone --> Save[임시저장 클릭]

    Save --> Auto[자동: DraftDocument 저장]
    Auto --> Switch[다른 업무 처리]

    Switch --> Later[나중에 다시 돌아옴]
    Later --> BottomTab[하단: 최근 작업 탭]

    BottomTab --> List[임시저장 목록 표시]
    List --> Load[불러오기 클릭]

    Load --> Resume[작업 이어하기]
    Resume --> Complete[발주 완료]

    style Start fill:#fff3e0
    style Auto fill:#f3e5f5
    style Complete fill:#e1f5e1
```

### 장점
```
✅ 언제든 작업 중단 가능
✅ 데이터 유실 방지
✅ 여러 발주서 동시 작성 가능
```

## 🎨 화면 전환 패턴

### 패턴 1: 탭 전환
```
메인 화면 내에서:
[발주] → [판매] → [재고]

┌────────────────────────┐
│ [발주][판매][재고]     │ ← 클릭하면 즉시 전환
├────────────────────────┤
│ (내용만 바뀜)          │
└────────────────────────┘
```
- 빠름 (즉시)
- 상단바 유지

---

### 패턴 2: 팝업 열기
```
발주/판매 화면에서:
[+ 품목 추가] 클릭

┌────────────────┐
│ 발주 화면      │
│   ┌──────────┐ │
│   │품목 선택 │ │ ← 팝업
│   └──────────┘ │
└────────────────┘
```
- 부모 화면 뒤로 Dim 처리
- [추가]/[취소] 후 팝업 닫힘

---

### 패턴 3: 거래처 전환
```
[거래처 변경] 클릭

A병원 → 확인 다이얼로그 → 거래처 선택 → B도매

전체 화면 리로드
(모든 데이터 B도매 기준으로 재조회)
```
- 느림 (데이터 재조회)
- 신중하게 사용
