### 1. 거래처 선택 화면
**파일명**: `CompanySelectionScreen.xaml`
**위치**: 앱 시작 시 맨 처음 나오는 화면

**무엇을 하나요?**
- 작업할 거래처를 선택합니다
- 2개 열 카드 형태로 표시됩니다

**화면 모습**:
```
┌─────────────────────────────────┐
│ 거래처 선택                      │
├─────────────────────────────────┤
│ 🔍 [검색...]  [유형▼] [정렬▼]  │
├─────────────────────────────────┤
│ ┌───────┐ ┌───────┐            │
│ │🏥A병원 │ │🏥B의원 │            │
│ │서울   │ │부산   │            │
│ │01-22  │ │01-20  │ ← 최근거래일│
│ └───────┘ └───────┘            │
│ ┌───────┐ ┌───────┐            │
│ │🏢C도매 │ │🏢D본사 │            │
│ │경기   │ │대전   │            │
│ │01-18  │ │01-15  │            │
│ └───────┘ └───────┘            │
└─────────────────────────────────┘
```

**클릭하면?**
→ 메인 화면으로 이동 (선택한 거래처로 고정)

### 2. 메인 화면 (작업 공간)
**파일명**: `MainWorkspace.xaml`
**위치**: 거래처 선택 후

**무엇을 하나요?**
- 모든 업무의 중심 화면
- 상단: 현재 거래처 표시
- 중간: 업무 선택 탭
- 하단: 선택한 탭의 내용

**화면 모습**:
```
┌──────────────────────────────────────┐
│ [현재 거래처: A병원 ▼] [거래처 변경]  │
├──────────────────────────────────────┤
│ [발주][견적][구매][판매][재고][품목] │
├──────────────────────────────────────┤
│                                      │
│    (선택된 탭의 내용 영역)            │
│                                      │
└──────────────────────────────────────┘
```

**역할**:
- [발주] 탭: 물건 주문하는 화면
- [견적] 탭: 견적서 만드는 화면
- [구매] 탭: 주문한 물건 입고 확인
- [판매] 탭: 물건 파는 화면
- [재고] 탭: 창고 재고 확인
- [품목] 탭: 물건 정보 관리

### 3. 품목 선택 팝업
**파일명**: `ProductSelectionModal.xaml`
**위치**: 발주/판매/견적 화면에서 팝업

**무엇을 하나요?**
- 발주하거나 판매할 물건을 선택합니다
- 모든 입력 화면에서 공통으로 사용합니다

**화면 모습**:
```
┌────────────────────────────┐
│ 품목 선택             [X]  │
├────────────────────────────┤
│ 🔍 [검색...]  [카테고리▼]  │
├────────────────────────────┤
│ ( ) P-001 원재료A  ₩50,000│
│ (●) P-002 테이프   ₩3,500 │ ← 선택됨
│ ( ) P-003 거즈     ₩12,000│
│ ( ) P-004 주사기   ₩8,000 │
├────────────────────────────┤
│ 수량: [___100___]          │
│ 금액: ₩350,000            │
│                            │
│ 💡 [+ 새 품목 등록]        │
│           [취소] [추가]    │
└────────────────────────────┘
```

**특징**:
- 발주 시: 사는 물건만 표시
- 판매 시: 파는 물건만 표시 + 재고 함께 표시
- 검색 가능
- 바로 새 품목 등록 가능

### 4. 발주 화면 (사는 것)
**파일명**: `OrderWindow.xaml`
**위치**: 메인 화면 → [발주] 탭

**무엇을 하나요?**
- 도매/본사에 물건 주문합니다

**화면 모습** (3분할):
```
┌─────────────────┬───────────────────┐
│ 좌: 전체 품목   │ 우: 최근 거래 품목 │
│ (40% 너비)      │ (60% 너비)        │
├─────────────────┼───────────────────┤
│ 🔍 [검색...]    │ 자주 시키는 품목:  │
│                 │                   │
│ ☐ 원재료A       │ ☑ 테이프          │
│   ₩50,000      │   수량: [_100_]   │
│                 │   단가: ₩3,500    │
│ ☐ 부품B         │                   │
│   ₩3,000       │ ☑ 거즈            │
│                 │   수량: [__50_]   │
│ ☐ 소독약        │   단가: ₩12,000   │
│   ₩5,000       │                   │
│                 │ 합계: ₩950,000    │
│ [+ 품목 추가]   │ [임시저장]        │
│                 │ [발주서 보내기]   │
├─────────────────┴───────────────────┤
│ 하단: 최근 거래 내역 (40% 높이)     │
│ [등록][임시저장][최근성사내역]      │
│                                     │
│ (선택된 탭의 내용)                  │
└─────────────────────────────────────┘
```

**사용법**:
1. 우측 "자주 시키는 품목"에서 수량만 입력 (빠름!)
2. 또는 좌측에서 검색해서 추가
3. [임시저장]: 나중에 이어서 작업
4. [발주서 보내기]: 발주 확정

**발주 후 자동 처리**:
- 구매 레코드 자동 생성
- 입고 예정 수량 증가

### 5. 판매 화면 (파는 것)
**파일명**: `SaleWindow.xaml`
**위치**: 메인 화면 → [판매] 탭

**무엇을 하나요?**
- 병원/의원에 물건을 판매합니다

**화면 모습** (발주와 비슷하지만 **재고 표시**):
```
┌─────────────────┬───────────────────┐
│ 좌: 전체 품목   │ 우: 자주 나가는   │
├─────────────────┼───────────────────┤
│ ☐ 테이프        │ ☑ 테이프          │
│   ₩3,500       │   수량: [__50_]   │
│   재고: 500 ✅  │   재고: 500 ✅    │← 재고 표시
│                 │                   │
│ ☐ 거즈          │ ☑ 거즈            │
│   ₩12,000      │   수량: [_300_]   │
│   재고: 200 ⚠️  │   재고: 200 ⚠️    │← 부족 경고
│                 │                   │
│                 │ 합계: ₩415,000    │
│                 │ [판매 등록]       │
└─────────────────┴───────────────────┘
```

**발주와 차이점**:
| 항목 | 발주 | 판매 |
|------|------|------|
| 재고 표시 | ❌ 불필요 | ✅ 필수 |
| 재고 검증 | ❌ 안 함 | ✅ 부족 시 경고 |
| 가격 | 구매 단가 | 판매 단가 |

**판매 후 자동 처리**:
- 재고 즉시 차감
- 채권(미수금) 자동 생성

### 6. 품목 관리 화면
**파일명**: `ProductManagementWindow.xaml`
**위치**: 메인 화면 → [품목] 탭

**무엇을 하나요?**
- 우리가 사고파는 물건 정보를 관리합니다

**화면 모습**:
```
┌─────────────────────────────────────┐
│ 품목 관리              [+ 품목 등록] │
├─────────────────────────────────────┤
│ [전체][📥사는것][📤파는것] [검색...] │
├─────────────────────────────────────┤
│ 유형│ 코드   │ 품목명    │ 단가    │
├─────┼────────┼───────────┼─────────┤
│ 📥  │ P-001  │ 원재료A   │ ₩50,000│
│ 📤  │ P-002  │ 테이프    │ ₩3,500 │
│ ↔️  │ P-003  │ 주사기    │ ₩8,000 │
│ 📤  │ P-004  │ 거즈      │ ₩12,000│
└─────────────────────────────────────┘
```

**품목 유형**:
- 📥 **사는 것** (Buy): 도매에서 구매하는 물건
- 📤 **파는 것** (Sell): 병원에 판매하는 물건
- ↔️ **둘다** (Both): 사기도 하고 팔기도 하는 물건

**왜 중요한가?**
→ 이 화면에 등록된 품목만 발주/판매에서 선택 가능!
