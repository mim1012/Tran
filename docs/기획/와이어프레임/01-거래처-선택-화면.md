## 🎨 화면 구성 요소

### 1. 헤더 영역
```
🏢 작업할 거래처를 선택하세요
```
- **목적**: 사용자에게 명확한 안내
- **폰트**: 20px, 굵게
- **색상**: `#333333`

### 2. 검색 영역
```
┌────────────────────────────────────────────────────────┐
│ 🔍 [거래처명 검색...]                        [타입▼]   │
└────────────────────────────────────────────────────────┘
```

**검색 입력**:
- 실시간 검색 (타이핑하면 즉시 필터링)
- Placeholder: "거래처명 검색..."
- 크기: 전체 너비의 70%

**타입 드롭다운**:
- 옵션: `[전체]` `[고객사]` `[공급사]`
- 크기: 전체 너비의 30%
- 기본값: `[전체]`

### 3. 거래처 카드 그리드 (2열)

#### 카드 구조 (하나의 카드)
```
┌──────────────────────┐
│ 🏥 A병원              │ ← 아이콘 + 거래처명
│                      │
│ 서울시 강남구...      │ ← 주소 (1줄 말줄임)
│                      │
│ 최근 거래: 2026-01-25 │ ← 최근 거래일
│ 미수금: ₩850,000     │ ← 채권/채무 금액
│                      │
│    [선택]            │ ← 선택 버튼
└──────────────────────┘
```

**카드 크기**:
- 너비: 45% (2열 배치, 간격 5%)
- 높이: 180px
- 패딩: 15px
- 테두리: 1px solid `#DDDDDD`
- 배경: `#FFFFFF`
- 마우스 오버 시: 테두리 `#1E90FF`, 그림자 추가

**카드 내용**:
1. **아이콘 + 거래처명**
   - 🏥 = 병원/의원 (고객사)
   - 🏭 = 도매/제조사 (공급사)
   - 폰트: 16px, 굵게

2. **주소**
   - 폰트: 12px, 회색 `#888888`
   - 1줄 말줄임 (`...`)

3. **최근 거래일**
   - 폰트: 12px
   - 색상: `#555555`

4. **채권/채무**
   - 미수금 (받을 돈): 빨간색 `#E74C3C`
   - 미지급 (줄 돈): 파란색 `#3498DB`
   - 폰트: 14px, 굵게

5. **[선택] 버튼**
   - 크기: 80px × 32px
   - 배경: `#1E90FF`
   - 텍스트: 흰색, 굵게
   - 가운데 정렬

### 4. 페이지네이션
```
◀ 1  2  3  4  5 ▶
```
- 한 페이지에 8개 카드 표시 (2열 × 4행)
- 현재 페이지: 굵게 + 파란색
- 화살표 클릭으로 이동

**[+ 새 거래처]**:

## 📊 데이터 요구사항

### 화면 로드 시 필요 데이터
```sql
SELECT
    c.Id,
    c.Name,
    c.Address,
    c.CompanyType,         -- 'Customer' or 'Supplier'
    c.LastTransactionDate,
    SUM(CASE WHEN d.Type = 'Sale' THEN d.Amount ELSE 0 END) AS Receivable,
    SUM(CASE WHEN d.Type = 'Purchase' THEN d.Amount ELSE 0 END) AS Payable
FROM Companies c
LEFT JOIN Documents d ON (c.Id = d.FromCompanyId OR c.Id = d.ToCompanyId)
WHERE d.State = 'Confirmed'
GROUP BY c.Id
ORDER BY c.LastTransactionDate DESC
```

### 정렬 기준
1. **최근 거래일 내림차순** (자주 쓰는 거래처가 위로)
2. 같은 날짜면 거래처명 가나다 순
