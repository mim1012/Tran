## 📝 품목 등록/편집 팝업

### 팝업 레이아웃
```
┌──────────────────────────────────────────┐
│ 품목 등록                            [X] │
├──────────────────────────────────────────┤
│                                          │
│  품목 코드 *: [P-      ]                 │
│               (자동 생성 가능)           │
│                                          │
│  품목명 *:    [                  ]       │
│                                          │
│  카테고리 *:  [원재료▼]                  │
│               - 원재료                   │
│               - 소모품                   │
│               - 의약품                   │
│               - 부품                     │
│               - 완제품                   │
│                                          │
│  거래유형 *:  ( ) 구매                   │
│               (●) 판매                   │
│               ( ) 둘다                   │
│                                          │
│  단위 *:      [개▼]                      │
│               - 개                       │
│               - kg                       │
│               - 병                       │
│               - 팩                       │
│                                          │
│  기본 단가:   [             ] 원         │
│                                          │
│  안전 재고:   [             ] (단위)     │
│                                          │
│  비고:        [                  ]       │
│               [                  ]       │
│                                          │
│                 [취소]      [저장]       │
└──────────────────────────────────────────┘
```

#### 필수 입력 필드 (*)
1. **품목 코드**: 중복 불가
2. **품목명**: 최대 100자
3. **카테고리**: 드롭다운 선택
4. **거래유형**: 라디오 버튼
   - 구매: 발주 시만 표시
   - 판매: 판매 시만 표시
   - 둘다: 발주/판매 모두 표시
5. **단위**: 개, kg, 병, 팩 등

#### 선택 입력 필드
1. **기본 단가**: 거래처별 단가가 없을 때 사용
2. **안전 재고**: 이 수량 미만 시 경고
3. **비고**: 품목 설명

#### [저장] 버튼
```
[저장]
```
- 크기: 100px × 36px
- 배경: `#1E90FF` (파란색)
- 유효성 검증:
  - 필수 필드 입력 여부
  - 품목 코드 중복 확인
  - 단가 음수 여부
  - 안전 재고 음수 여부

## 📊 데이터 요구사항

### 품목 목록 쿼리
```sql
SELECT
    p.Id,
    p.Code,
    p.Name,
    p.Category,
    p.TransactionType,
    p.Unit,
    COALESCE(i.ConfirmedQuantity, 0) AS StockQuantity,
    p.SafetyStockLevel,
    p.IsActive
FROM Products p
LEFT JOIN Inventory i ON p.Id = i.ProductId
WHERE p.IsActive = 1
ORDER BY p.Code ASC
```

### 품목 삭제 가능 여부 확인
```sql
-- 연관 데이터 확인
SELECT COUNT(*)
FROM (
    SELECT OrderId FROM OrderItems WHERE ProductId = @ProductId
    UNION ALL
    SELECT SaleId FROM SaleItems WHERE ProductId = @ProductId
    UNION ALL
    SELECT DocumentId FROM DocumentItems WHERE ProductId = @ProductId
) AS RelatedRecords

-- 결과가 0이면 삭제 가능
```

### 품목 등록 시 처리
```csharp
// 1. Product 생성
var product = new Product
{
    Code = request.Code,
    Name = request.Name,
    Category = request.Category,
    TransactionType = request.TransactionType,
    Unit = request.Unit,
    DefaultPrice = request.DefaultPrice,
    SafetyStockLevel = request.SafetyStockLevel,
    Description = request.Description,
    IsActive = true,
    CreatedAt = DateTime.Now
};
await _dbContext.Products.AddAsync(product);

// 2. Inventory 초기 레코드 생성
var inventory = new Inventory
{
    ProductId = product.Id,
    ConfirmedQuantity = 0,
    PendingInQuantity = 0,
    PendingOutQuantity = 0
};
await _dbContext.Inventory.AddAsync(inventory);

await _dbContext.SaveChangesAsync();
```

## 💡 핵심 포인트

### 1. 품목 마스터 = 모든 데이터의 기준
- 발주/판매/재고 모두 품목 마스터 참조
- 품목 코드 중복 절대 불가

### 2. 거래유형 (TransactionType)
- **구매**: 발주 시에만 표시
- **판매**: 판매 시에만 표시
- **둘다**: 발주/판매 모두 표시

### 3. 안전 삭제 (Soft Delete)
- 거래 이력이 있으면 삭제 불가
- IsActive = false로 비활성화
- 데이터 무결성 유지

### 4. 재고 연동
- 품목 등록 시 Inventory 레코드 자동 생성
- 재고 수량은 별도 화면에서 관리
