## 🎨 화면 구성 요소

### 1. 상단: 필터 영역

```
구매 관리                    [상태▼ 전체] [기간▼]  [검색...]
```

**[상태▼] 드롭다운**:
- `[전체]` (기본)
- `[⏳입고대기]` - PurchaseState = PendingDelivery
- `[✅입고완료]` - PurchaseState = Delivered
- `[⚠️부분입고]` - PurchaseState = PartiallyDelivered

**[기간▼] 드롭다운**:
- `[전체]`
- `[오늘]`
- `[이번 주]`
- `[이번 달]` (기본)
- `[3개월]`

**[검색...]**:
- 발주번호 / 공급사명 검색
- 실시간 필터링

|------|------|------|
| **No** | 8% | 순번 |
| **품목명** | 25% | 품목 이름 |
| **발주수량** | 15% | 원래 발주 수량 (읽기 전용) |
| **입고수량** | 17% | **인라인 편집** (숫자 입력) |
| **불량수량** | 17% | **인라인 편집** (숫자 입력) |
| **상태** | 13% | 아이콘 + 텍스트 |
| **여백** | 5% | |

#### 입고수량 입력
- 기본값: 발주수량과 동일 (편의)
- 입고수량 > 발주수량: 인라인 경고 (주황 테두리)
- 입고수량 + 불량수량 > 발주수량: 인라인 에러 (빨강 테두리)
- Tab 키로 셀 간 이동

#### [📦 입고 확정 F5] 버튼
- 크기: 150px × 36px
- 배경: `#9B59B6` (보라색) - 구매 화면 고유 색상
- 텍스트: 흰색, 굵게
- 클릭 시:
  1. 👤 사용자: 입고수량 확인 (실물 검수 후)
  2. 👤 사용자: [입고 확정] 클릭
  3. 🤖 자동: `Inventory.ConfirmedQuantity += 입고수량`
  4. 🤖 자동: `Inventory.PendingInQuantity -= 입고수량`
  5. 🤖 자동: `InventoryTransaction` 이력 기록 (Type=Inbound)
  6. 🤖 자동: `Purchase.State = Delivered`
  7. → 토스트 알림: "입고 완료 - 재고에 반영되었습니다"

```
1. 경리: [구매] 탭 클릭 (Ctrl+3)

   │                            │
   │      [확정]    [취소]      │
   └────────────────────────────┘
8. → 🤖 재고 자동 반영
9. → 상태: ⏳입고대기 → ✅입고완료
```

### 시나리오 2: 불량 발생
```
1. 경리: 반창고 불량수량 [3] 입력
2. → 입고수량 자동 조정: 200 - 3 = 197개가 재고 반영
3. → 불량 3개는 별도 기록
4. 경리: [입고 확정]
5. → Inventory 반영: 반창고 +197개
6. → DefectRecord 생성: 반창고 3개 (Phase 3)
```

### 시나리오 3: 부분 입고
```
1. 경리: 테이프 입고수량을 [70]으로 수정 (100개 중 70개만 도착)
2. → 나머지 30개는 미입고
3. 경리: [입고 확정]
4. → Purchase.State = PartiallyDelivered
5. → 테이프 재고 +70개
6. → PendingInQuantity: 100 → 30 (잔여)
7. → 마스터 목록 상태: ⚠️부분입고
```

## 📊 데이터 요구사항

### 구매 목록 쿼리
```sql
SELECT
    o.OrderNumber,
    c.Name AS SupplierName,
    COUNT(oi.Id) AS ItemCount,
    o.TotalAmount,
    p.State AS PurchaseState,
    o.CreatedAt
FROM Purchases p
INNER JOIN Orders o ON p.OrderId = o.Id
INNER JOIN Companies c ON o.ToCompanyId = c.Id
INNER JOIN OrderItems oi ON o.Id = oi.OrderId
WHERE o.FromCompanyId = @CurrentCompanyId
GROUP BY o.Id
ORDER BY o.CreatedAt DESC
```

### 입고 확정 처리
```csharp
// 1. 재고 반영
foreach (var item in purchaseItems)
{
    var inventory = await _dbContext.Inventory
        .FirstOrDefaultAsync(i => i.ProductId == item.ProductId);

    var actualInbound = item.ReceivedQuantity - item.DefectQuantity;
    inventory.ConfirmedQuantity += actualInbound;
    inventory.PendingInQuantity -= item.OrderedQuantity;

    // 2. 이력 기록
    _dbContext.InventoryTransactions.Add(new InventoryTransaction
    {
        ProductId = item.ProductId,
        Type = TransactionType.Inbound,
        Quantity = actualInbound,
        ReferenceType = "Purchase",
        ReferenceId = purchase.Id,
        CreatedAt = DateTime.Now
    });
}

// 3. Purchase 상태 변경
purchase.State = allDelivered
    ? PurchaseState.Delivered
    : PurchaseState.PartiallyDelivered;

await _dbContext.SaveChangesAsync();
```
