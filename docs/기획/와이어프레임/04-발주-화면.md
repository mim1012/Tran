## 📊 데이터 요구사항

### 최근 거래 품목 쿼리
```sql
-- 최근 3개월 거래 품목 (빈도 순)
SELECT
    p.Id,
    p.Code,
    p.Name,
    COUNT(oi.Id) AS TransactionCount,
    COALESCE(cp.Price, p.DefaultPrice) AS Price,
    COALESCE(i.ConfirmedQuantity, 0) AS StockQuantity
FROM Products p
INNER JOIN OrderItems oi ON p.Id = oi.ProductId
INNER JOIN Orders o ON oi.OrderId = o.Id
LEFT JOIN CompanyPrices cp ON (p.Id = cp.ProductId AND cp.CompanyId = @CurrentCompanyId)
LEFT JOIN Inventory i ON p.Id = i.ProductId
WHERE o.FromCompanyId = @CurrentCompanyId
  AND o.CreatedAt >= DATEADD(MONTH, -3, GETDATE())
  AND p.TransactionType IN ('Buy', 'Both')
GROUP BY p.Id, p.Code, p.Name, cp.Price, p.DefaultPrice, i.ConfirmedQuantity
ORDER BY TransactionCount DESC
LIMIT 10
```

### 발주 확정 시 처리
```csharp
// 1. Order 생성
var order = new Order
{
    OrderNumber = GenerateOrderNumber(),
    FromCompanyId = currentCompanyId,
    ToCompanyId = supplierCompanyId,
    State = OrderState.Requested,
    Items = orderItems,
    TotalAmount = totalAmount,
    CreatedAt = DateTime.Now
};
await _dbContext.Orders.AddAsync(order);

// 2. Purchase 자동 생성
var purchase = new Purchase
{
    OrderId = order.Id,
    State = PurchaseState.Created,
    ExpectedDeliveryDate = order.RequestedDeliveryDate
};
await _dbContext.Purchases.AddAsync(purchase);

// 3. 입고예정 수량 반영
foreach (var item in orderItems)
{
    var inventory = await _dbContext.Inventory
        .FirstOrDefaultAsync(i => i.ProductId == item.ProductId);

    if (inventory != null)
    {
        inventory.PendingInQuantity += item.Quantity;
    }
}

await _dbContext.SaveChangesAsync();
```
