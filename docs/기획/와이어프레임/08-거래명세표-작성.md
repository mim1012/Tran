## 🔄 상호작용 흐름

### 시나리오 1: 수동 작성 (새 문서)
```
1. 사용자: [거래명세표] 탭에서 [+ 새 문서] 클릭
2. → 거래명세표 작성 화면 열림
3. → 문서번호 자동 생성: DOC-2026-006
4. → 거래처: 현재 거래처로 고정
5. 사용자: [+ 품목 추가] 클릭
6. → 품목 선택 팝업 열림
7. 사용자: 품목 선택 + 수량 입력 → [추가]
8. → 품목 목록에 추가
9. → 합계 자동 계산
10. 사용자: 비고 입력 (선택)
11. 사용자: [발송] 클릭
12. → Document 생성 (state=Draft)
13. → ContentHash 계산
14. → 상태 전환: Draft → Sent
15. → P2P 전송
16. → 창 닫기 + 성공 메시지
```

### 시나리오 2: 임시저장 후 나중에 발송
```
1. 사용자: 품목 2개 추가
2. 사용자: [임시저장] 클릭
3. → Document 생성 (state=Draft)
4. → 창 닫기
5. (나중에)
6. 사용자: [거래명세표] 탭에서 해당 문서 [보기] 클릭
7. → "09. 거래명세표 상세" 화면
8. 사용자: [발송] 버튼 클릭 (상세 화면에서)
9. → State: Draft → Sent
```

### 시나리오 3: 판매 → 자동 생성 → 수정
```
1. (이전에 [판매] 탭에서 판매 확정)
2. → Document 자동 생성 (state=Draft, Sale과 연결)
3. 사용자: [거래명세표] 탭에서 해당 문서 [보기] 클릭
4. → "09. 거래명세표 상세" 화면
5. → 자동 생성된 품목 목록 표시
6. 사용자: 내용 확인 (수정 불가 - 판매 데이터와 동기화)
7. 사용자: [발송] 클릭
8. → State: Draft → Sent
```

## 📊 데이터 요구사항

### 문서 생성 시 처리
```csharp
// 1. Document 생성
var document = new Document
{
    DocumentNumber = GenerateDocumentNumber(), // DOC-YYYY-NNN
    DocumentType = "Manual", // 수동 작성 (vs "Sale", "Purchase")
    FromCompanyId = currentCompanyId,
    ToCompanyId = currentCompanyId, // Phase 1: 같은 거래처
    State = DocumentState.Draft,
    Items = documentItems,
    Remarks = remarks,
    CreatedAt = DateTime.Now,
    CreatedBy = currentUserId
};

// 2. ContentHash 계산 (중요!)
document.ContentHash = _hashService.CalculateHash(document);

await _dbContext.Documents.AddAsync(document);

// 3. [발송] 선택 시 상태 전환
if (shouldSend)
{
    var stateLog = await _stateTransitionService.TransitionAsync(
        document,
        DocumentState.Sent,
        currentUserId,
        "문서 발송"
    );

    await _dbContext.DocumentStateLogs.AddAsync(stateLog);
}

await _dbContext.SaveChangesAsync();
```

### ContentHash 계산 (무결성 보장)
```csharp
public class HashService
{
    public string CalculateHash(Document document)
    {
        var content = new
        {
            document.DocumentNumber,
            document.FromCompanyId,
            document.ToCompanyId,
            Items = document.Items.Select(item => new
            {
                item.ProductId,
                item.ProductName,
                item.Quantity,
                item.UnitPrice,
                item.Amount
            }).OrderBy(i => i.ProductId)
        };

        var json = JsonSerializer.Serialize(content);
        using var sha256 = SHA256.Create();
        var bytes = Encoding.UTF8.GetBytes(json);
        var hash = sha256.ComputeHash(bytes);
        return Convert.ToBase64String(hash);
    }
}
```

## 💡 핵심 포인트

### 1. ContentHash 계산 (필수)
- 문서 생성 시 항상 ContentHash 계산
- 품목 정보 변경 시 재계산
- 확정 후 변조 검증에 사용

### 2. 수동 작성 vs 자동 생성
- **수동**: DocumentType = "Manual"
- **자동**: DocumentType = "Sale" or "Purchase", SaleId/PurchaseId 연결

### 3. 상태 전환
- Draft → Sent (발송 시)
- StateTransitionService 사용 (권한 체크)

### 4. Phase 1 제약
- 거래처 고정 (현재 거래처만)
- Phase 2에서 거래처 선택 가능
