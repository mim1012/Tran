### 3. 탭 영역 (핵심!)

#### 전체 탭 구조
```
┌────────────────────────────────────────────────────────────────────────┐
│ [📥발주][📋견적][📦구매][📤판매][📊재고][🏷️품목] | [📄거래명세표][💰정산][📜이력] │
```

**좌측: ERP 기능 탭 (6개)**
1. **[📥발주]** `Ctrl+1` - 공급사에 주문 (사는 것) → **파란색** 액센트
2. **[📋견적]** `Ctrl+2` - 견적서 작성/관리
3. **[📦구매]** `Ctrl+3` - 입고 관리
4. **[📤판매]** `Ctrl+4` - 고객사에 판매 (파는 것) → **초록색** 액센트
5. **[📊재고]** `Ctrl+5` - 재고 현황 조회
6. **[🏷️품목]** `Ctrl+6` - 품목 마스터 관리

**우측: 거래명세표 시스템 (3개)**
7. **[📄거래명세표]** `Ctrl+7` - Document 목록/상태 관리
8. **[💰정산]** `Ctrl+8` - 확정된 문서 기준 정산
9. **[📜이력]** `Ctrl+9` - DocumentStateLog 조회

## 🔄 상호작용 흐름

### 시나리오 1: 발주 탭 사용
```
1. 사용자: [발주] 탭 클릭
2. → 콘텐츠 영역이 발주 화면으로 변경
3. → 3분할 레이아웃 표시
4. 사용자: 발주 입력 (품목 선택, 수량 입력)
5. 사용자: [발주 확정]
6. → 자동: Purchase 생성, 입고예정 반영
7. → 하단 상태바 "미확정 발주" 숫자 업데이트
```

### 시나리오 2: 판매 → 거래명세표 연동
```
1. 사용자: [판매] 탭 클릭
2. 판매 입력 (테이프 100개)
3. 사용자: [판매 확정]
4. → 자동: Sale 생성, 재고 차감
5. → 자동: Document 생성 (state=Draft)
6. → 알림 표시: "거래명세표가 생성되었습니다"
7. 사용자: [거래명세표] 탭 클릭
8. → 방금 생성된 문서 표시
9. 사용자: 문서 선택 → [발송]
10. → Document.State: Draft → Sent
```

### 시나리오 3: 거래처 전환
```
1. 사용자: [거래처 변경] 클릭
2. → 확인 다이얼로그:
   ┌────────────────────────────┐
   │ ⚠️ 거래처 변경             │
   │                            │
   │ 미저장 데이터가 있습니다.   │
   │ 임시저장 하시겠습니까?      │
   │                            │
   │  [임시저장]  [취소]  [확인]│
   └────────────────────────────┘

3-A. [확인] 클릭:
     → 거래처 선택 화면으로 이동

3-B. [임시저장] 클릭:
     → 현재 작업 DraftDocument로 저장
     → 거래처 선택 화면으로 이동

3-C. [취소] 클릭:
     → 현재 화면 유지
```

### 1. 미저장 데이터가 있을 때 탭 전환
```
┌────────────────────────────┐
│ ⚠️ 미저장 데이터           │
│                            │
│ 현재 작업을 저장할까요?     │
```

```
🟡 확정 대기: 거래명세표 2건
```
- 주황색으로 표시
