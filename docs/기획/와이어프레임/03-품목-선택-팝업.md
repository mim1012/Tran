## 📊 데이터 요구사항

### 화면 로드 시 쿼리
```sql
SELECT
    p.Id,
    p.Code,
    p.Name,
    p.Category,
    p.TransactionType,  -- 'Buy', 'Sell', 'Both'
    p.Unit,             -- '개', 'kg', '병', '팩'
    COALESCE(cp.Price, p.DefaultPrice) AS Price,
    COALESCE(i.ConfirmedQuantity, 0) AS StockQuantity,
    p.SafetyStockLevel
FROM Products p
LEFT JOIN CompanyPrices cp ON (p.Id = cp.ProductId AND cp.CompanyId = @CurrentCompanyId)
LEFT JOIN Inventory i ON (p.Id = i.ProductId)
WHERE p.IsActive = 1
ORDER BY p.Name ASC
```

### 필터링 로직
```csharp
// 검색어 필터
if (!string.IsNullOrEmpty(searchText))
{
    products = products.Where(p =>
        p.Name.Contains(searchText) ||
        p.Code.Contains(searchText));
}

// 카테고리 필터
if (selectedCategory != "전체")
{
    products = products.Where(p => p.Category == selectedCategory);
}

// 타입 필터
if (selectedType == "구매 가능")
{
    products = products.Where(p =>
        p.TransactionType == "Buy" ||
        p.TransactionType == "Both");
}
```
