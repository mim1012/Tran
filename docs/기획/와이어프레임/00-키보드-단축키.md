# 00. 키보드 워크플로 & 단축키 정의서

> **적용 대상**: 전 화면 공통
> **원칙**: 경리가 전화 받으면서 한 손으로 입력 가능해야 한다
> **목표**: 마우스 없이 발주/판매 1건 완료 가능

---

## 1. 전역 단축키 (앱 어디서나)

| 단축키 | 동작 | 비고 |
|--------|------|------|
| `Ctrl+1` ~ `Ctrl+6` | ERP 탭 전환 (발주/견적/구매/판매/재고/품목) | 탭 순서 고정 |
| `Ctrl+7` ~ `Ctrl+9` | 거래명세표/정산/이력 탭 전환 | |
| `Ctrl+F` | 현재 화면 검색 필드 포커스 | |
| `Ctrl+N` | 새 항목 추가 (컨텍스트별) | 발주 탭: 새 발주, 품목 탭: 새 품목 |
| `Ctrl+S` | 임시저장 | 발주/판매 등록 탭에서 |
| `Ctrl+Home` | 거래처 변경 (거래처 선택 화면) | |
| `Esc` | 팝업 닫기 / 현재 작업 취소 | |
| `F1` | 도움말 | Phase 2 |

---

## 2. 발주/판매 화면 단축키

| 단축키 | 동작 | 비고 |
|--------|------|------|
| `F5` | **확정** (발주 확정 / 판매 확정) | 핵심 단축키 |
| `F6` | 임시저장 | = `Ctrl+S` |
| `F7` | 품목 선택 팝업 열기 | = [+ 품목 추가] |
| `Enter` | 우측 패널: 수량 입력 후 즉시 추가 | 포커스가 수량 필드일 때 |
| `Tab` | 다음 입력 필드로 이동 | Tab 순서 아래 정의 |
| `Delete` | 선택된 품목 행 삭제 | 등록 탭 테이블에서 |
| `↑` / `↓` | 등록 탭 테이블 행 이동 | |

### 발주/판매 Tab 순서 (포커스 흐름)

```
① 좌측 검색 필드
    ↓ Tab
② 좌측 품목 카드 첫 번째 [추가] 버튼
    ↓ Tab
③ 우측 첫 번째 품목 수량 입력
    ↓ Tab
④ 우측 첫 번째 [추가] 버튼
    ↓ Tab
⑤ 우측 두 번째 품목 수량 입력
    ↓ ... (반복)
    ↓ Tab (우측 마지막 이후)
⑥ 하단 등록 탭 첫 번째 수량 셀 (인라인 편집)
    ↓ Tab
⑦ 비고 입력
    ↓ Tab
⑧ [임시저장] 버튼
    ↓ Tab
⑨ [확정] 버튼
```

### 빠른 판매 시나리오 (키보드만)

```
1. Ctrl+4          → [판매] 탭 활성화
2. Tab Tab Tab      → 우측 첫 번째 품목 수량 필드 포커스
3. "100" 입력       → 수량 입력
4. Enter            → 하단 등록 탭에 즉시 추가
5. Tab              → 다음 품목 수량 필드
6. "50" 입력        → 수량 입력
7. Enter            → 추가
8. F5               → [판매 확정]
9. Enter            → 확인 다이얼로그 승인

총 키 입력: 약 15회, 소요 시간: 약 10초
```

## 3. 품목 선택 팝업 단축키

| 단축키 | 동작 | 비고 |
|--------|------|------|
| `Ctrl+F` | 검색 필드 포커스 | |
| `Space` | 체크박스 토글 (다중 선택 모드) | |
| `↑` / `↓` | 목록 행 이동 | |
| `Tab` | 수량 입력 필드로 이동 | |
| `Enter` | [추가] 실행 | |
| `Esc` | [취소] (팝업 닫기) | |
| `더블클릭` | 즉시 추가 (수량 1) | 마우스 사용 시 |

### 팝업 Tab 순서

```
① 검색 입력
    ↓ Tab
② 카테고리 드롭다운
    ↓ Tab
③ 타입 드롭다운
    ↓ Tab
④ 품목 목록 (↑↓ 탐색, Space 선택)
    ↓ Tab
⑤ 수량 입력
    ↓ Tab
⑥ [추가] 버튼
    ↓ Tab
⑦ [취소] 버튼
```

## 8. 포커스 표시 (Focus Indicator)

모든 포커스 가능한 요소에 **파란색 외곽선** 표시:

```
기본:       [ 수량 입력 ]
포커스 시:  [| 수량 입력 |]  ← 2px solid #1E90FF 테두리 + 연한 파란 배경 #E8F4FF
```

- 버튼: 2px solid `#1E90FF` 테두리
- 입력 필드: 2px solid `#1E90FF` 테두리 + 배경 `#E8F4FF`
- 카드: 2px solid `#1E90FF` 테두리 + 그림자
- DataGrid 행: 배경 `#E8F4FF`

**WCAG 2.4.7**: 포커스 인디케이터는 항상 보여야 한다.

## 9. 화면별 단축키 오버레이

`F1` 또는 `Ctrl+/` 입력 시 현재 화면의 단축키를 **반투명 오버레이**로 표시:

```
┌─────────────────────────────────────┐
│  ⌨️ 키보드 단축키                    │
│                                     │
│  F5    확정                         │
│  F6    임시저장                     │
│  F7    품목 추가                    │
│  Ctrl+F  검색                      │
│  Enter   추가/확인                  │
│  Esc     취소                       │
│                                     │
│  (아무 키나 누르면 닫힘)              │
└─────────────────────────────────────┘
```
