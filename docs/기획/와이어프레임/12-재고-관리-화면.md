## 🎨 화면 구성 요소

### 1. 상단: 필터 영역

```
재고 현황                    [카테고리▼] [상태▼]  [검색...]
                                                  [📋 재고 조정]
```

**[카테고리▼] 드롭다운**:
- `[전체]` (기본)
- `[소모품]`
- `[원재료]`
- `[의약품]`
- `[부품]`
- `[완제품]`

**[상태▼] 드롭다운**:
- `[전체]` (기본)
- `[✅ 정상]`
- `[⚠️ 부족]` - 안전재고 미만
- `[❌ 위험]` - 재고 10개 미만 또는 0

**[검색...]**:
- 품목명/코드 검색
- 실시간 필터링

**[📋 재고 조정] 버튼**:
- 크기: 120px × 36px
- 배경: `#F39C12` (주황)
- 텍스트: 흰색
- 클릭 시: 재고 조정 팝업 열기
- **이것만 수동 조작 가능**

|------|------|------|

| **코드** | 12% | 품목 코드 |
| **확정재고** | 15% | `Inventory.ConfirmedQuantity` |
| **입고예정** | 13% | `Inventory.PendingInQuantity` (초록 텍스트) |
| **출고예정** | 13% | `Inventory.PendingOutQuantity` (빨강 텍스트) |
| **상태** | 15% | 아이콘 + 텍스트 |
| **여백** | 12% | |

#### 수량 표시
```

입고예정: +100     (초록 #27AE60, 14px)
출고예정: -50      (빨강 #E74C3C, 14px)
```

#### 상태 판정 로직
```csharp
if (confirmedQuantity <= 0)
    return "❌ 위험";    // 빨강
else if (confirmedQuantity < safetyStockLevel)
    return "⚠️ 부족";    // 주황
else
    return "✅ 정상";    // 초록
```

#### 행 스타일
- 기본: `#FFFFFF`, 높이 40px
- 마우스 오버: `#F0F8FF`
- 위험 행: 배경 `#FFF5F5` (연한 빨강)
- 부족 행: 배경 `#FFFAF0` (연한 주황)
- 짝수 행: `#F9F9F9`
- **읽기 전용** (인라인 편집 없음)

## 🔄 상호작용 흐름

### 시나리오 1: 재고 현황 조회 (가장 빈번)
```
1. 경리: [재고] 탭 클릭 (Ctrl+5)
2. → 전체 품목 재고 현황 표시
3. 경리: [상태▼] → [⚠️ 부족] 선택
4. → 안전재고 미만 품목만 필터링
5. 경리: "주사기" 행 클릭
6. → 하단 이력 탭에 주사기 입출고 이력 표시
7. 경리: 확인 후 [발주] 탭으로 이동 (Ctrl+1)

소요 시간: 약 5초
```

### 시나리오 2: 재고 조정 (실사 후)
```
1. 경리: 실물 재고 확인 (창고에서)
2. 경리: [📋 재고 조정] 클릭
3. → 재고 조정 팝업 열림
4. 경리: 품목 "소독약" 선택
5. → 현재 재고: 5개 표시
6. 경리: 조정 유형 "감소", 수량 "2" 입력
7. → 조정 후 재고: 3개 표시
8. 경리: 사유 "실사 결과 파손품 2개 폐기"
9. 경리: [조정 확정] 클릭
10. → Inventory.ConfirmedQuantity: 5 → 3
11. → InventoryTransaction 기록 (Type=Adjustment, -2)
12. → 토스트: "✅ 재고 조정 완료 - 소독약: 5개 → 3개"
```

### 시나리오 3: 자동 반영 확인
```
경리: 아까 [판매] 탭에서 테이프 100개 판매 확정함
경리: [재고] 탭 클릭
→ 테이프 확정재고: 500 → 400으로 자동 차감되어 있음
→ 하단 이력: "01-25 테이프 📤출고 -100 판매 SAL-004"

별도 조작 필요 없음 - 자동화 결과만 확인
```

## 📊 데이터 요구사항

### 재고 현황 쿼리
```sql
SELECT
    p.Name AS ProductName,
    p.Code,
    p.Unit,
    COALESCE(i.ConfirmedQuantity, 0) AS ConfirmedQuantity,
    COALESCE(i.PendingInQuantity, 0) AS PendingInQuantity,
    COALESCE(i.PendingOutQuantity, 0) AS PendingOutQuantity,
    p.SafetyStockLevel,
    p.Category
FROM Products p
LEFT JOIN Inventory i ON p.Id = i.ProductId
WHERE p.IsActive = 1
ORDER BY
    CASE
        WHEN COALESCE(i.ConfirmedQuantity, 0) <= 0 THEN 0           -- 위험 먼저
        WHEN COALESCE(i.ConfirmedQuantity, 0) < p.SafetyStockLevel THEN 1  -- 부족
        ELSE 2                                                        -- 정상
    END,
    p.Name ASC
```

### 입출고 이력 쿼리
```sql
SELECT
    it.CreatedAt,
    p.Name AS ProductName,
    it.Type,        -- 'Inbound', 'Outbound', 'Adjustment'
    it.Quantity,
    it.ReferenceType,  -- 'Purchase', 'Sale', 'Manual'
    it.ReferenceId,
    it.Note
FROM InventoryTransactions it
INNER JOIN Products p ON it.ProductId = p.Id
WHERE (@ProductId IS NULL OR it.ProductId = @ProductId)
  AND it.CreatedAt >= @StartDate
ORDER BY it.CreatedAt DESC
```

## 🔗 연결 화면

### 자동 반영 소스 (이 화면을 건드리지 않고 자동 변동)
- 발주 확정 (04) → `PendingInQuantity` 증가
- 입고 확정 (11) → `ConfirmedQuantity` 증가, `PendingInQuantity` 감소
- 판매 확정 (05) → `ConfirmedQuantity` 감소

### 수동 조작
- [📋 재고 조정] → `ConfirmedQuantity` 증감 + 이력 기록

## 💡 핵심 포인트

### 1. 읽기 전용 원칙
- 재고 테이블은 **직접 편집 불가**
- 모든 변동은 발주/입고/판매에서 **자동 반영**
- 유일한 수동 조작: [재고 조정] (실사 후)

### 2. 자동화 결과 확인
- 경리가 "판매 확정 후 재고가 줄었나?" 확인하는 용도
- 이력 탭에서 모든 변동 추적 가능

### 3. 위험 품목 우선 표시
- 정렬 기본값: 위험 → 부족 → 정상 순
- 발주가 필요한 품목이 가장 먼저 보임
