## 🔄 상호작용 흐름

### 시나리오 1: 문서 목록 조회
```
1. 사용자: [거래명세표] 탭 클릭
2. → 현재 거래처의 문서 목록 조회
3. → 최신순 정렬 (생성일 내림차순)
4. → 통계 정보 계산 및 표시
```

### 시나리오 2: 상태 필터링
```
1. 사용자: 필터 드롭다운 클릭
2. 사용자: [확정] 선택
3. → 확정된 문서만 표시
4. → 통계 정보 업데이트
```

### 시나리오 3: 문서 상세 보기
```
1. 사용자: "DOC-2026-001" 행의 [보기] 클릭
2. → "09. 거래명세표 상세" 화면으로 이동
3. → 문서 ID 전달
4. → 상세 정보 + 상태 기계 표시
```

### 시나리오 4: 신규 문서 작성 (수동)
```
1. 사용자: [+ 새 문서] 클릭
2. → "08. 거래명세표 작성" 화면으로 이동
3. → 품목 선택 및 입력
4. 사용자: [임시저장] or [발송]
5. → Document 생성 (state=Draft or Sent)
6. → 문서 목록으로 돌아오기
7. → 새 문서 표시
```

### 시나리오 5: 판매 → 자동 생성 문서 확인
```
1. (이전에 [판매] 탭에서 판매 확정)
2. → Document 자동 생성 (state=Draft)
3. 사용자: [거래명세표] 탭 클릭
4. → 자동 생성된 문서 표시 (상태: 작성중)
5. 사용자: [보기] 클릭
6. → 상세 화면에서 내용 확인
7. 사용자: [발송] 버튼 클릭
8. → State: Draft → Sent
9. → 거래처에 P2P 전송 (또는 이메일)
```

## 📊 데이터 요구사항

### 문서 목록 쿼리
```sql
SELECT
    d.Id,
    d.DocumentNumber,
    d.CreatedAt,
    d.State,
    d.FromCompanyId,
    d.ToCompanyId,
    c.Name AS CompanyName,
    SUM(di.Amount) AS TotalAmount,
    d.SaleId,
    d.PurchaseId
FROM Documents d
INNER JOIN Companies c ON (
    CASE
        WHEN @CurrentCompanyId = d.FromCompanyId THEN d.ToCompanyId
        ELSE d.FromCompanyId
    END = c.Id
)
INNER JOIN DocumentItems di ON d.Id = di.DocumentId
WHERE (d.FromCompanyId = @CurrentCompanyId OR d.ToCompanyId = @CurrentCompanyId)
  AND d.IsActive = 1
GROUP BY d.Id, d.DocumentNumber, d.CreatedAt, d.State, d.FromCompanyId, d.ToCompanyId, c.Name, d.SaleId, d.PurchaseId
ORDER BY d.CreatedAt DESC
```

### 통계 쿼리
```sql
-- 확정 건수 + 금액
SELECT
    COUNT(*) AS ConfirmedCount,
    SUM(TotalAmount) AS ConfirmedAmount
FROM Documents d
INNER JOIN (
    SELECT DocumentId, SUM(Amount) AS TotalAmount
    FROM DocumentItems
    GROUP BY DocumentId
) di ON d.Id = di.DocumentId
WHERE (d.FromCompanyId = @CurrentCompanyId OR d.ToCompanyId = @CurrentCompanyId)
  AND d.State = 'Confirmed'
  AND d.IsActive = 1

-- 발송 건수
SELECT COUNT(*) FROM Documents
WHERE State = 'Sent' AND IsActive = 1

-- 작성중 건수
SELECT COUNT(*) FROM Documents
WHERE State = 'Draft' AND IsActive = 1
```

### DocumentViewModel
```csharp
public class DocumentViewModel : ViewModelBase
{
    public int Id { get; set; }
    public string DocumentNumber { get; set; }
    public DateTime CreatedAt { get; set; }
    public DocumentState State { get; set; }
    public decimal TotalAmount { get; set; }

    // 상태 배지 색상
    public string StateBadgeBackground => State switch
    {
        DocumentState.Draft => "#F0F0F0",
        DocumentState.Sent => "#E8F1FF",
        DocumentState.Received => "#FFF4E5",
        DocumentState.Confirmed => "#E6F4EA",
        _ => "#F0F0F0"
    };

    public string StateBadgeTextColor => State switch
    {
        DocumentState.Draft => "#555555",
        DocumentState.Sent => "#1E5EFF",
        DocumentState.Received => "#E67700",
        DocumentState.Confirmed => "#1E7F34",
        _ => "#555555"
    };

    public string StateDisplayText => State switch
    {
        DocumentState.Draft => "작성중",
        DocumentState.Sent => "발송",
        DocumentState.Received => "수신",
        DocumentState.Confirmed => "확정",
        DocumentState.RevisionRequested => "수정요청",
        _ => "알 수 없음"
    };
}
```
