## 🎨 화면 구성 요소

### 1. 상태 기계 영역 (★ 핵심)

```
┌────────────────────────────────────────────────────────────┐
│ 📊 상태 기계                                                │
│ ──────────────────────────────────────────────────────     │
│                                                             │
│  [작성중] → [발송] → [수신] → [확정] ✅                    │
│                              ↘ [수정요청]                   │
│                                                             │
│  현재 상태: 확정 (2026-01-25 15:30)                        │
│  해시: 5a7f... (검증 완료 ✅)                               │
└────────────────────────────────────────────────────────────┘
```

#### 상태 흐름 시각화
```
[작성중] → [발송] → [수신] → [확정] ✅
                          ↘ [수정요청]
```

**상태별 색상** (docs/UI_UX_GUIDELINES.md):
- **작성중**: 회색 `#F0F0F0` / `#555555`
- **발송**: 파란색 `#E8F1FF` / `#1E5EFF`
- **수신**: 주황색 `#FFF4E5` / `#E67700`
- **확정**: 초록색 `#E6F4EA` / `#1E7F34` ✅
- **수정요청**: 주황색 `#FFF4E5` / `#E67700`

**현재 상태 강조**:
- 현재 상태에 **✅** 표시
- 굵은 글씨 + 배경 강조

#### 해시 검증 표시
```
해시: 5a7f... (검증 완료 ✅)
```
- **확정 상태**일 때만 표시
- ContentHash 앞 8자리 표시
- 검증 결과:
  - ✅ 검증 완료 (초록색)
  - ❌ 변조 감지 (빨간색) - 경고!

## 📊 데이터 요구사항

### 문서 상세 쿼리
```sql
SELECT
    d.Id,
    d.DocumentNumber,
    d.CreatedAt,
    d.State,
    d.ContentHash,
    d.FromCompanyId,
    d.ToCompanyId,
    d.SaleId,
    d.PurchaseId,
    d.Remarks,
    fc.Name AS FromCompanyName,
    tc.Name AS ToCompanyName
FROM Documents d
INNER JOIN Companies fc ON d.FromCompanyId = fc.Id
INNER JOIN Companies tc ON d.ToCompanyId = tc.Id
WHERE d.Id = @DocumentId
```

### 품목 정보 쿼리
```sql
SELECT
    di.ProductId,
    di.ProductName,
    di.Quantity,
    di.UnitPrice,
    di.Amount,
    p.Unit
FROM DocumentItems di
INNER JOIN Products p ON di.ProductId = p.Id
WHERE di.DocumentId = @DocumentId
ORDER BY di.Id ASC
```

### 상태 이력 쿼리
```sql
SELECT
    dsl.Id,
    dsl.FromState,
    dsl.ToState,
    dsl.TransitionedAt,
    dsl.TransitionedBy,
    dsl.Reason,
    u.Name AS UserName,
    c.Name AS CompanyName
FROM DocumentStateLogs dsl
INNER JOIN Users u ON dsl.TransitionedBy = u.Id
INNER JOIN Companies c ON u.CompanyId = c.Id
WHERE dsl.DocumentId = @DocumentId
ORDER BY dsl.TransitionedAt DESC
```

### 상태 전환 처리
```csharp
// StateTransitionService 사용
var service = new StateTransitionService();

// 1. 전환 가능 여부 확인
if (!service.CanTransition(document.State, targetState))
{
    throw new InvalidOperationException("이 상태로 전환할 수 없습니다.");
}

// 2. 권한 확인
if (!service.HasPermission(currentUserId, document, targetState))
{
    throw new UnauthorizedAccessException("권한이 없습니다.");
}

// 3. 전환 실행
var stateLog = await service.TransitionAsync(
    document,
    targetState,
    currentUserId,
    reason
);

// 4. 로그 저장
await _dbContext.DocumentStateLogs.AddAsync(stateLog);

// 5. Confirmed 시 해시 검증
if (targetState == DocumentState.Confirmed)
{
    var isValid = _hashService.VerifyHash(document);
    if (!isValid)
    {
        throw new HashMismatchException("문서가 변조되었습니다!");
    }
}

await _dbContext.SaveChangesAsync();
```

## 📝 개발 참고사항

### ViewModel
```csharp
public class DocumentDetailViewModel : ViewModelBase
{
    public int DocumentId { get; set; }
    public string DocumentNumber { get; set; }
    public DateTime CreatedAt { get; set; }
    public DocumentState State { get; set; }
    public string ContentHash { get; set; }
    public bool IsHashValid { get; set; }

    public string CompanyName { get; set; }
    public string DocumentType { get; set; } // "Manual", "Sale", "Purchase"
    public string LinkedTransactionNumber { get; set; } // Sale-XXXX or Order-XXXX

    public ObservableCollection<DocumentItemViewModel> Items { get; set; }
    public decimal TotalAmount => Items.Sum(i => i.Amount);

    public string Remarks { get; set; }

    public ObservableCollection<StateLogViewModel> StateLogs { get; set; }

    // 버튼 가시성
    public bool CanSend => State == DocumentState.Draft;
    public bool CanDelete => State == DocumentState.Draft;
    public bool CanConfirm => State == DocumentState.Received;
    public bool CanRequestRevision => State == DocumentState.Received;
    public bool CanPrint => State == DocumentState.Confirmed;

    public ICommand SendCommand { get; }
    public ICommand ConfirmCommand { get; }
    public ICommand RequestRevisionCommand { get; }
    public ICommand DeleteCommand { get; }
    public ICommand PrintCommand { get; }
    public ICommand DownloadPdfCommand { get; }
}
```

## 💡 핵심 포인트

### 1. 상태 기계 시각화
- 사용자가 현재 상태와 가능한 전환을 한눈에 파악
- "상태가 곧 권한이다" 원칙 준수

### 2. ContentHash 검증
- Confirmed 상태에서 해시 검증
- 변조 감지 시 경고
- 증거 효력 보장

### 3. 불변성 (Immutability)
- Confirmed 후 수정 불가
- DocumentStateLog로 모든 변경 추적
- 분쟁 시 증거 자료

### 4. 권한 기반 버튼 표시
- 현재 상태에 따라 버튼 동적 표시
- StateTransitionService로 권한 체크
