#### 표시 정보
**미수금 (Receivable)**:
- 의미: 판매한 금액 (받을 돈)
- 색상: 빨간색 `#E74C3C` (채권)
- 계산: 확정된 판매 문서 합계 - 입금된 금액

**미지급 (Payable)**:
- 의미: 발주한 금액 (줄 돈)
- 색상: 파란색 `#3498DB` (채무)
- 계산: 확정된 발주 문서 합계 - 지급한 금액

**순액 (Net)**:
- 계산: 미수금 - 미지급
- 색상:
  - 양수 (받을 돈 많음): 빨간색 `#E74C3C`
  - 음수 (줄 돈 많음): 파란색 `#3498DB`
- 폰트: 18px, 굵게

## 📊 데이터 요구사항

### 요약 정보 쿼리
```sql
-- 미수금 (받을 돈) - 판매
SELECT
    COUNT(*) AS Count,
    SUM(TotalAmount) AS Amount
FROM Documents d
INNER JOIN (
    SELECT DocumentId, SUM(Amount) AS TotalAmount
    FROM DocumentItems
    GROUP BY DocumentId
) di ON d.Id = di.DocumentId
WHERE d.FromCompanyId = @CurrentCompanyId
  AND d.State = 'Confirmed'
  AND d.DocumentType = 'Sale'
  AND d.IsSettled = 0  -- 미입금
  AND d.ConfirmedAt >= @StartDate
  AND d.ConfirmedAt <= @EndDate

-- 미지급 (줄 돈) - 발주
SELECT
    COUNT(*) AS Count,
    SUM(TotalAmount) AS Amount
FROM Documents d
INNER JOIN (
    SELECT DocumentId, SUM(Amount) AS TotalAmount
    FROM DocumentItems
    GROUP BY DocumentId
) di ON d.Id = di.DocumentId
WHERE d.FromCompanyId = @CurrentCompanyId
  AND d.State = 'Confirmed'
  AND d.DocumentType = 'Purchase'
  AND d.IsSettled = 0  -- 미지급
  AND d.ConfirmedAt >= @StartDate
  AND d.ConfirmedAt <= @EndDate
```

### 확정 문서 목록 쿼리
```sql
SELECT
    d.Id,
    d.DocumentNumber,
    d.ConfirmedAt,
    d.DocumentType,  -- 'Sale' or 'Purchase'
    SUM(di.Amount) AS TotalAmount,
    d.IsSettled,
    CASE
        WHEN d.DocumentType = 'Sale' AND d.IsSettled = 0 THEN '미입금'
        WHEN d.DocumentType = 'Sale' AND d.IsSettled = 1 THEN '입금완료'
        WHEN d.DocumentType = 'Purchase' AND d.IsSettled = 0 THEN '미지급'
        WHEN d.DocumentType = 'Purchase' AND d.IsSettled = 1 THEN '지급완료'
    END AS SettlementStatus
FROM Documents d
INNER JOIN DocumentItems di ON d.Id = di.DocumentId
WHERE (d.FromCompanyId = @CurrentCompanyId OR d.ToCompanyId = @CurrentCompanyId)
  AND d.State = 'Confirmed'
  AND d.ConfirmedAt >= @StartDate
  AND d.ConfirmedAt <= @EndDate
GROUP BY d.Id, d.DocumentNumber, d.ConfirmedAt, d.DocumentType, d.IsSettled
ORDER BY d.ConfirmedAt DESC
```

### Excel 다운로드 처리
```csharp
public async Task<string> ExportToExcelAsync(
    int companyId,
    DateTime startDate,
    DateTime endDate,
    string statusFilter)
{
    var documents = await GetSettlementDocumentsAsync(
        companyId, startDate, endDate, statusFilter);

    using var workbook = new XLWorkbook();
    var worksheet = workbook.Worksheets.Add("정산 내역");

    // 헤더
    worksheet.Cell(1, 1).Value = "문서번호";
    worksheet.Cell(1, 2).Value = "확정일";
    worksheet.Cell(1, 3).Value = "유형";
    worksheet.Cell(1, 4).Value = "금액";
    worksheet.Cell(1, 5).Value = "상태";

    // 데이터
    int row = 2;
    foreach (var doc in documents)
    {
        worksheet.Cell(row, 1).Value = doc.DocumentNumber;
        worksheet.Cell(row, 2).Value = doc.ConfirmedAt.ToString("yyyy-MM-dd");
        worksheet.Cell(row, 3).Value = doc.DocumentType == "Sale" ? "판매" : "발주";
        worksheet.Cell(row, 4).Value = doc.TotalAmount;
        worksheet.Cell(row, 5).Value = doc.SettlementStatus;
        row++;
    }

    var fileName = $"정산_{companyName}_{startDate:yyyy-MM}.xlsx";
    var filePath = Path.Combine(downloadsPath, fileName);
    workbook.SaveAs(filePath);

    return filePath;
}
```

### SettlementDocumentViewModel
```csharp
public class SettlementDocumentViewModel : ViewModelBase
{
    public int Id { get; set; }
    public string DocumentNumber { get; set; }
    public DateTime ConfirmedAt { get; set; }
    public string DocumentType { get; set; } // "Sale" or "Purchase"
    public decimal TotalAmount { get; set; }
    public bool IsSettled { get; set; }

    public string DocumentTypeDisplay => DocumentType == "Sale" ? "판매" : "발주";

    public string SettlementStatus
    {
        get
        {
            if (DocumentType == "Sale")
                return IsSettled ? "입금완료" : "미입금";
            else
                return IsSettled ? "지급완료" : "미지급";
        }
    }

    public string StatusBadgeBackground
    {
        get
        {
            if (DocumentType == "Sale")
                return IsSettled ? "#E6F4EA" : "#FFEBEE";
            else
                return IsSettled ? "#F0F0F0" : "#E8F1FF";
        }
    }
}
```

## 💡 핵심 포인트

### 1. 확정 문서만 정산 대상
- State = Confirmed인 문서만 표시
- Draft/Sent/Received 제외
- 증거 효력이 있는 문서만 정산

### 2. 미수금 vs 미지급
- **미수금** (Receivable): 판매 → 받을 돈 (빨간색)
- **미지급** (Payable): 발주 → 줄 돈 (파란색)
- 순액으로 전체 현황 파악

### 3. 기간별 필터링
- 이번 달, 지난 달, 지난 3개월, 올해
- 사용자 지정 기간
- 정산 계획 수립에 활용

### 4. Excel 다운로드
- 회계 시스템 연동
- 보고서 작성
- 증빙 자료
