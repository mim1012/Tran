## 🎨 화면 구성 요소

### 1. 좌측: 견적서 작성 영역 (65%)

#### 거래처 + 유효기간
```
거래처: 🏥 A병원 (고정)              ← Phase 1: 거래처 고정 모드
유효기간: [2026-03-10 📅]            ← DatePicker, 기본 30일 후
```

#### 품목 목록 테이블
| 컬럼 | 너비 | 설명 |
|------|------|------|
| **No** | 6% | 순번 |
| **품목명** | 22% | 품목 이름 |
| **규격** | 12% | 규격/사양 (인라인 편집) |
| **수량** | 12% | 수량 (인라인 편집) |
| **단가** | 18% | **단가 직접 입력** (핵심!) |
| **금액** | 18% | 수량 × 단가 (자동 계산) |
| **삭제** | 7% | [X] 버튼 |
| **여백** | 5% | |

**단가 입력 특징**:
- 기존 거래처 단가(CompanyPrice) 자동 로드
- 경리가 **직접 수정 가능** (견적 핵심 기능)
- 변경된 단가는 우측 미리보기에 표시

#### 합계 영역
```
합계: ₩1,110,000 (VAT별도)
VAT:  ₩111,000
총액: ₩1,221,000
```
- 합계: 18px, 굵게
- 총액: 20px, 굵게, 파란색 `#1E90FF`

#### 하단 버튼
```
[임시저장 F6]  [발송 F8]  [확정 F5]
```

**[임시저장 F6]**: `#95A5A6` 회색
**[발송 F8]**: `#1E90FF` 파란색
- 클릭 시: QuotationState = Sent
- 발송 방법 선택 팝업: [이메일] [팩스] [직접전달]

**[확정 F5]**: `#27AE60` 초록색
- 클릭 시:
  1. 👤 확인 다이얼로그 (단가 변경/품목 등록 안내)
  2. 🤖 CompanyPrice 업데이트 (거래처별 단가)
  3. 🤖 PriceHistory 이력 저장
  4. 🤖 CompanyProduct 자동 등록
  5. → 토스트: "견적 확정 - 단가 및 품목이 자동 반영되었습니다"

### 2. 우측: 견적 정보 + 미리보기 (35%)

```
📊 견적 정보
견적번호: QT-0210-001
상태: ✏️작성중
버전: v1

단가 변경 미리보기:
  테이프  ₩3,000 → ₩3,500 (+₩500)
  거즈    (신규) ₩12,000

품목 등록 미리보기:
  거즈 → A병원 품목에 추가됨
```

**핵심 기능**: 견적서에서 단가를 바꾸면, 확정 시 어떤 변경이 발생하는지 **미리 보여준다**.
- 기존 단가와 다른 품목: 변경 전→후 표시
- 거래처에 없는 품목: "신규" 표시
- CompanyProduct에 미등록된 품목: "품목에 추가됨" 표시

```

10. 경리: [확정 F5] 클릭
11. → 확인 다이얼로그:

    │                                    │
    │ 다음 변경이 자동 적용됩니다:        │
    │                                    │

    │   거즈: ₩11,000 → ₩12,000        │
    │                                    │
    │ 📦 품목 등록:                      │
    │   소독약 → A병원 거래 품목 추가    │
    │                                    │
    │ 이후 발주/판매 시 변경된 단가가     │
```

### 시나리오 2: 기존 견적 기반 새 견적
```
1. 경리: 하단 [견적 목록]에서 이전 견적 QT-0125-003 클릭
2. → 상단에 해당 견적 내용 로드 (읽기 전용)
3. 경리: [복사하여 새 견적] 버튼 클릭
4. → 새 견적번호 생성, 편집 가능 상태
5. 경리: 단가/수량 수정 후 [확정]
```

### 시나리오 3: 발송 후 확정
```
1. 경리: 견적서 작성 완료
2. 경리: [발송 F8] 클릭
3. → 발송 방법 선택: [이메일] [팩스] [직접전달]
4. 경리: [이메일] 선택
5. → 상태: ✏️작성중 → 📤발송
6. (거래처 검토 대기...)
7. 경리: 거래처에서 확인 연락 옴
8. 경리: [확정 F5] 클릭
9. → 자동 처리 실행
```

## 📊 데이터 요구사항

### 단가 변경 미리보기 로직
```csharp
public class QuotationPreviewService
{
    public List<PriceChangePreview> GetPriceChanges(Quotation quotation)
    {
        var previews = new List<PriceChangePreview>();

        foreach (var item in quotation.Items)
        {
            var currentPrice = _context.CompanyPrices
                .Where(p => p.CompanyId == quotation.CompanyId
                         && p.ProductId == item.ProductId)
                .OrderByDescending(p => p.EffectiveDate)
                .FirstOrDefault();

            if (currentPrice == null)
            {
                previews.Add(new PriceChangePreview
                {
                    ProductName = item.Product.Name,
                    IsNew = true,
                    NewPrice = item.UnitPrice
                });
            }
            else if (currentPrice.UnitPrice != item.UnitPrice)
            {
                previews.Add(new PriceChangePreview
                {
                    ProductName = item.Product.Name,
                    OldPrice = currentPrice.UnitPrice,
                    NewPrice = item.UnitPrice,
                    Difference = item.UnitPrice - currentPrice.UnitPrice
                });
            }
        }

        return previews;
    }
}
```

### ViewModel
```csharp
public class QuotationViewModel : ViewModelBase
{
    // 견적서 작성
    public Quotation CurrentQuotation { get; set; }
    public ObservableCollection<QuotationItemViewModel> Items { get; set; }
    public DateTime ValidUntil { get; set; }
    public string Memo { get; set; }

    // 미리보기
    public ObservableCollection<PriceChangePreview> PriceChanges { get; set; }
    public ObservableCollection<ProductRegistrationPreview> ProductRegistrations { get; set; }

    // 하단 탭
    public ObservableCollection<QuotationListItemViewModel> QuotationList { get; set; }
    public ObservableCollection<PriceHistoryViewModel> PriceHistory { get; set; }

    // 합계
    public decimal Subtotal => Items.Sum(i => i.Amount);
    public decimal Vat => Subtotal * 0.1m;
    public decimal Total => Subtotal + Vat;

    // Commands
    public ICommand AddProductCommand { get; }     // F7
    public ICommand SaveDraftCommand { get; }       // F6
    public ICommand SendCommand { get; }            // F8
    public ICommand ConfirmCommand { get; }         // F5
    public ICommand CopyToNewCommand { get; }
}
```
