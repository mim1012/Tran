## 🎯 Tran 앱이란?

### 한 줄 요약
**의료기기 유통 관리 프로그램** (발주/판매/재고 관리)

### 누가 사용?
- 판매 담당자
- 구매 담당자
- 재고 관리자
- 영업 관리자

### 핵심 기능
1. **발주/판매** - 주문 받고 팔기
2. **재고 관리** - 입고/출고 관리
3. **견적서** - 견적 작성/발송

---

## 🔑 핵심 개념: "거래처 고정 모드" (Phase 1)

### 무엇인가요?
```
한 번에 한 거래처만 작업
→ 다른 거래처 작업 시 명시적으로 전환
```

### 왜 이렇게?
- ✅ 빨리 만들 수 있음
- ✅ 사용자 혼란 방지
- ✅ "지금 어느 업체 작업중?" 고민 불필요

### 나중에는?
Phase 2에서 **탭 기능** 추가 예정
→ 여러 거래처 동시 작업 가능

## 📱 최우선 화면 6개

```
P0 (최우선) - 이것만 있으면 앱 동작:

1. 거래처 선택 화면
2. 메인 화면 (작업 공간)
3. 품목 선택 팝업 ★
4. 발주 화면 (사는 것)
5. 판매 화면 (파는 것)
6. 품목 관리 화면

★ = 여러 곳에서 재사용
```

## 🚀 개발 일정 (예상)
