## 🎯 Tran 앱이란? (간단 요약)

### 무엇을 하는 앱인가요?

**의료기기 유통 관리 프로그램**입니다.

```
병원/의원 ←→ 우리 회사 ←→ 도매/본사
        (발주/판매)      (구매)
```

### 누가 사용하나요?

- **판매 담당자**: 병원에 물건 팔 때
- **구매 담당자**: 도매에서 물건 살 때
- **재고 담당자**: 창고 재고 확인할 때
- **영업 관리자**: 견적서 만들 때

### 핵심 기능 3가지

1. **발주/판매 입력**
   - 병원에서 주문 받으면 → 판매 입력
   - 우리가 도매에 주문하면 → 발주 입력

2. **재고 관리**
   - 입고되면 → 재고 증가
   - 출고되면 → 재고 감소
   - 재고 부족 시 → 경고

3. **견적서 작성**
   - 신규 거래처에 견적서 발송
   - 견적 확정 시 → 단가 자동 저장

## 🔑 Phase 1 핵심 컨셉: "거래처 고정 모드"

### 무엇인가요?

```
기존 방식 (나중에 구현):
┌────┐┌────┐┌────┐
│A병원││B도매││C병원│  ← 여러 업체 동시 작업
└────┘└────┘└────┘

Phase 1 방식 (지금 만들 것):
┌──────────┐
│  A병원   │  ← 한 번에 한 업체만
└──────────┘
      ↓
[전환 버튼] 클릭
      ↓
┌──────────┐
│  B도매   │  ← 다른 업체로 전환
└──────────┘
```

### 왜 이렇게 하나요?

**장점**:
- ✅ 만들기 쉽습니다 (빨리 출시 가능)
- ✅ 사용자가 헷갈리지 않습니다
- ✅ "지금 어느 업체 작업중이지?" 고민 불필요

**단점**:
- ❌ 업체 전환 시 화면 전체 리로드
- ❌ 두 업체 동시 비교 불가능

**결론**: Phase 1에서 빨리 출시 → 사용자 피드백 수집 → Phase 2에서 탭 기능 추가

## 📊 최우선 화면 6개 (P0)

### 1. 거래처 선택 화면
**역할**: 앱 시작 시 어느 업체와 작업할지 선택

```
┌─────────┬─────────┐
│  A병원  │  B의원  │
│ 서울    │ 부산    │
└─────────┴─────────┘
┌─────────┬─────────┐
│  C도매  │  D본사  │
│ 경기    │ 대전    │
└─────────┴─────────┘
```

**클릭하면?** → 메인 화면으로 이동 (해당 업체로 고정)

---

### 2. 메인 화면
**역할**: 모든 업무의 중심

```
┌─────────────────────────────────┐
│ [현재: A병원] [거래처 변경]      │
├─────────────────────────────────┤
│ [발주][견적][판매][재고][품목]  │
├─────────────────────────────────┤
│                                 │
│    (선택된 탭의 내용)            │
│                                 │
└─────────────────────────────────┘
```

---

### 3. 품목 선택 팝업
**역할**: 발주/판매할 물건을 선택하는 팝업창

```
┌─────────────────────────────┐
│ 품목 선택              [X]  │
├─────────────────────────────┤
│ 🔍 [검색...]               │
│                             │
│ ☐ 테이프 10EA   ₩3,500     │
│ ☑ 거즈 1BOX     ₩12,000    │ ← 선택
│ ☐ 주사기 100EA  ₩8,000     │
│                             │
│ 수량: [___50___]            │
│           [취소] [추가]     │
└─────────────────────────────┘
```

**어디서 사용?**
- 발주 입력 시
- 판매 입력 시
- 견적서 작성 시

---

### 4. 발주 화면 (사는 것)
**역할**: 도매/본사에서 물건 주문

```
┌───────────────┬─────────────────┐
│ 전체 품목     │ 최근 거래 품목  │
│               │                 │
│ ☐ 테이프      │ ☑ 테이프 [100] │ ← 수량만 입력
│ ☐ 거즈        │ ☑ 거즈   [50]  │
│               │                 │
│               │ [발주서 보내기] │
├───────────────┴─────────────────┤
│ [등록][임시저장][최근 성사내역] │
└─────────────────────────────────┘
```

**특징**:
- 좌측: 검색해서 찾기
- 우측: 자주 쓰는 품목 빠르게 입력
- 하단: 임시저장된 발주서 불러오기

---

### 5. 판매 화면 (파는 것)
**역할**: 병원/의원에 물건 판매

```
┌───────────────┬─────────────────┐
│ 전체 품목     │ 자주 나가는 품목│
│               │                 │
│ ☐ 테이프      │ ☑ 테이프 [50]  │
│   재고: 500   │   재고: 500 ✅ │ ← 재고 표시
│               │                 │
│ ☐ 거즈        │ ☑ 거즈   [300] │
│   재고: 200   │   재고: 200 ⚠️ │ ← 재고 부족 경고
│               │                 │
│               │ [판매 등록]     │
└───────────────┴─────────────────┘
```

**발주와 차이점**:
- 재고 수량 표시 (없으면 판매 불가)
- 재고 부족 시 빨간색 경고

---

### 6. 품목 관리 화면
**역할**: 우리가 사고파는 물건 등록

```
┌─────────────────────────────────┐
│ 품목 관리          [+ 품목 등록]│
├─────────────────────────────────┤
│ [전체][📥사는것][📤파는것][검색] │
├─────────────────────────────────┤
│ 유형 품목명      단가      상태 │
│ 📥  원재료A    ₩50,000   활성 │
│ 📤  테이프     ₩3,500    활성 │
│ ↔️  주사기     ₩8,000    활성 │
└─────────────────────────────────┘
```

**품목 유형**:
- 📥 **사는 것**: 도매에서 구매하는 물건
- 📤 **파는 것**: 병원에 판매하는 물건
- ↔️ **둘다**: 사기도 하고 팔기도 하는 물건

## 📌 자주 묻는 질문 (FAQ)

### Q1. 왜 "거래처 고정 모드"인가요?
**A**: 빠른 출시를 위해서입니다. 탭 방식은 나중에 추가합니다.

### Q2. 품목 등록은 누가 하나요?
**A**: 관리자가 미리 등록합니다. 일반 사용자는 등록된 품목만 선택 가능합니다.

### Q3. 재고가 없으면 판매 못 하나요?
**A**: 네, 재고가 0이면 판매 불가능합니다. (재고 관리 원칙)

### Q4. 임시저장은 얼마나 보관되나요?
**A**: 사용자가 삭제하기 전까지 영구 보관됩니다.

### Q5. Excel 업로드 기능은?
**A**: 견적서와 품목 일괄 등록에서 지원 예정입니다.
